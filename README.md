# Estimating Tail Entropy and Local Intrinsic Dimensionality

This repository contains the code, LaTeX report, and figures for the project **"Estimating Tail Entropy and Local Intrinsic Dimensionality"** presented for CS786854 (Spring 2025).

## 📘 Overview

This project investigates the relationship between **Tail Entropy**—an information-theoretic measure of uncertainty in the tail of a distribution—and **Local Intrinsic Dimensionality (LID)**, a geometric measure of local data complexity.

We introduce and compare two classes of tail entropy estimators:
- **Direct spacing-based estimators** using order statistics
- **LID-based estimators** derived from asymptotic relationships

## 📊 Key Results

- LID-based estimators offer higher robustness and lower variance in tail-sparse regimes.
- Theoretical asymptotic relationships between LID and tail entropy are empirically validated.
- Experiments use synthetic datasets (Uniform and Truncated Exponential).
